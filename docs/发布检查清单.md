# 发布检查清单（每次发文前后过一遍）

> 配合台账 ledger/publish_ledger.csv 使用；本清单保证每次发布可追踪、可复盘。

## 一、发文前（内容与素材）
- [ ] 内容文件就绪：title / description / body / price / media_files 填写完整（content/*.yaml）
- [ ] **素材状态**：视频/图片文件真实存在、格式为平台支持（mp4/jpg/png/webp）、路径为绝对路径
- [ ] 平台适配：platform_overrides 已按平台定制（如闲鱼价格、头条图文标题）
- [ ] **发布时间**：避开平台审核高峰（建议工作日 10:00-12:00 / 18:00-22:00）；当前版本为手动触发，时间由执行时刻决定
- [ ] 合规自检：无违禁词、无侵权素材、符合各平台社区规范

## 二、发布中（执行观察）
- [ ] 有头浏览器窗口可见，逐步观察每一步（slow_mo 已默认 300ms）
- [ ] 遇登录墙/验证码 → 在浏览器中人工处理 → 创建 verification/HUMAN_DONE 继续
- [ ] publish 模式下控制台确认 y/n 后才真正点击发布（auto_submit_default=ask）
- [ ] 单平台失败不阻塞其余平台（all 模式逐台执行、逐台写台账）

## 三、发布后（台账与复盘指标）
- [ ] 确认台账新增记录：python run_publish.py --stats
- [ ] **复盘指标**（建议每周汇总一次）：
  - 发布成功率 = published / 总执行数（按台账 status 统计）
  - 草稿转化率 = published / draft_saved
  - 失败归因 = failed 记录的 detail 字段分类（选择器失效 / 登录过期 / 风控拦截）
  - 平台分布 = by_platform 是否均衡
- [ ] 平台侧数据（播放/曝光/互动）在各自后台查看，可人工回填台账（result_url 字段已留作品链接）
- [ ] 失败记录的截图（verification/）与 detail 归档，选择器失效按 HANDOVER §6.1 修复

## 四、可追踪记录
- 台账 CSV（人工读）：ledger/publish_ledger.csv —— Excel 直接打开
- 台账 JSONL（机器读）：ledger/publish_ledger.jsonl
- 截图留痕：verification/*.png（entry/editor/filled/done/error 全阶段）
- 统计命令：python run_publish.py --stats
